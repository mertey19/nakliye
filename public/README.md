# public/

Statik dosyalar. Buradaki her şey site köküne servis edilir.

## images/

Firmanın **gerçek** fotoğrafları buraya konur ve `src/config/photos.ts`
içinden referans verilir. Stok fotoğraf kullanılmaz.

Önerilen adlandırma:

```
kansu-can-nakliye-arac.webp
kansu-can-nakliye-ekip.webp
evden-eve-nakliyat.webp
esya-paketleme.webp
```

Dosya adına anahtar kelime doldurulmaz; alt metni fotoğrafta gerçekten
görüneni anlatır.
